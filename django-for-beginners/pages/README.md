# pages

First project from *Django for Beginners* (Chapter 3, "Pages App"): a
homepage and an about page, with no database involved. The point of
this stage is the bare URL -> View -> Template flow described in the
book folder's [top-level README](../README.md), before models enter
the picture in later chapters.

## The idea

Every later chapter in this book adds one more piece on top of this
same flow (a database-backed model, forms, user auth, ...), so this
first project deliberately keeps two of the four MVT pieces empty:

- **No models** — nothing here is stored in a database, so there's no
  `makemigrations`/`migrate` step yet.
- **Two static views** — `home` and `about` each just render a
  template with no per-request logic beyond passing in a couple of
  hardcoded context variables.

That leaves `urls.py`, `views.py`, and templates to actually exercise.

## Project layout

```
pages/
  manage.py
  django_project/         # project package (generated by `startproject django_project .`)
    settings.py              # pages.apps.PagesConfig added to INSTALLED_APPS
    urls.py                  # root URLconf — includes pages.urls
    wsgi.py / asgi.py
  pages/                   # the app (generated by `startapp pages`)
    views.py                  # home, about
    urls.py                   # app-level routes, included from django_project/urls.py
    templates/pages/           # home.html, about.html (namespaced under pages/ per Django's APP_DIRS convention)
    apps.py / admin.py / models.py / tests.py / migrations/   # scaffolded, unused at this stage
```

Created from the `django-for-beginners/` folder with:

```bash
django-admin startproject django_project pages
cd pages
python manage.py startapp pages
```

Kept as Django's own generated layout (project package + app as
siblings under the stage folder) rather than this repo's usual flat
per-stage shape — same reasoning as `django-impatient/moviereviews`:
following the framework's own convention is more legible to anyone who
already knows Django.

## Running

From the repo root with `.venv` active:

```bash
python django-for-beginners/pages/manage.py runserver
```
