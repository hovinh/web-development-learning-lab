# message-board

Second project from *Django for Beginners* (Chapter 4, "Message Board
App"). Builds on `pages/`'s bare URL -> View -> Template flow by
introducing the fourth MVT piece: a **Model**, backed by the database
and editable through Django's built-in admin site.

## The idea

`Post` is deliberately the simplest possible model - one `TextField`,
no title, no timestamp - so the chapter's focus stays on wiring a
model through to a page rather than on the model's shape. Every post
is listed on the homepage as a plain `<li>`, oldest-created first
(no custom ordering yet).

Sample data comes from a management command
(`message_board/management/commands/seed_posts.py`), not typed by
hand into the admin site - same pattern as
`django-impatient/moviereviews`'s `seed_movies.py`/`seed_news.py`, so
the 3 starter posts are a re-runnable file instead of one-off manual
entry that's lost if the database is ever reset.

## Project layout

```
message-board/
  manage.py
  django_project/            # project package (generated by `startproject django_project .`)
    settings.py                 # message_board.apps.MessageBoardConfig added to INSTALLED_APPS
    urls.py                     # root URLconf - includes message_board.urls
    wsgi.py / asgi.py
  message_board/              # the app (generated by `startapp message_board`)
    models.py                   # Post (just a `text` TextField)
    admin.py                    # registers Post with the admin site
    views.py                    # home - lists all posts
    urls.py                     # app-level routes, included from django_project/urls.py
    templates/message_board/     # home.html - <ul> of posts, no base.html yet at this stage
    management/commands/         # seed_posts.py - creates the 3 sample posts
    migrations/
```

Created from the `django-for-beginners/` folder with:

```bash
django-admin startproject django_project message-board
cd message-board
python manage.py startapp message_board
```

Same reasoning as `pages/` for keeping Django's own generated layout
rather than this repo's usual flat per-stage shape.

## Running

From the repo root with `.venv` active:

```bash
python django-for-beginners/message-board/manage.py migrate
python django-for-beginners/message-board/manage.py seed_posts
python django-for-beginners/message-board/manage.py runserver
```
